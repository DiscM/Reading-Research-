# Compare potential duplicates without modeling versions

Canopy compares differently hashed Research Paper Source PDFs that appear to represent the same work, but it does not merge them or record edition relationships. The user may add the candidate as a separate Document, keep the existing Document, or cancel remaining additions; true version history and annotation migration remain deferred because they require a trustworthy Edition model. Other Document Kinds use exact content duplicate detection only because bibliographic similarity rules would be noisy for recurring lecture, note, and handout titles.
