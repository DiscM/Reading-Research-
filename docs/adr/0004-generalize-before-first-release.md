# Generalize Canopy before its first public release

Canopy will ship first as an offline, PDF-backed Document workspace rather than release the narrower research Paper model and broaden it afterward. This accepts additional first-release scope for Collections, generalized metadata, Document Notes, multi-selection, and indexed search while the development store is empty and the schema is still unreleased, avoiding immediate terminology and migration debt without weakening source-identity or annotation safety.
